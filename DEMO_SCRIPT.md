# Ninety-second demo

Use the exact release candidate that passed the physical checklist. Keep the
HUD, fallback labels, and emergency pause visible. Rehearse this sequence three
times and record actual timings.

| Time | Action and line |
| --- | --- |
| 0–15s | Say: “Signal turns your hand into both a touch interface and a programmable command layer for your Mac.” In Touch or Hybrid Mode, use the index pose to move the real cursor and quick-pinch once into Signal. |
| 15–28s | Hold a pinch and move vertically to scroll, release, then pinch and move horizontally to zoom. Keep detected state and latency visible; do not narrate settings. |
| 28–50s | Open Build Command and submit the prefilled focus request. Show the structured three-step preview and its confirmations, approve it, and map it to `thumbs_up`. If the planner is down, visibly label the deterministic seeded result. |
| 50–68s | Hold thumbs up through the progress ring. Show playlist/focus fallback, hear “Focus mode,” and show the Discord success receipt or clearly labeled local fallback receipt. |
| 68–82s | Show the already-prepared controlled Teach by Demo timeline briefly, then trigger `c_shape` to open TextEdit, send Command-N, and type the demo phrase. |
| 82–90s | Show the public unlisted profile page/code. Say: “Any gesture can become a repeatable workflow, while the same hand still controls the computer.” |

## Recovery cues

- Planner/API failure: choose the seeded validated plan; say “offline fallback.”
- Spotify app failure: open the public playlist or branded focus page.
- Discord failure/unconfigured secret: show the in-app receipt labeled fallback.
- Global recorder failure: use the controlled Action Lab timeline.
- C shape instability before the demo: run one calibration capture; do not
  pretend fixture mode is live.
- Public profile failure: show local export/import while keeping the landing
  page available.
- Unsafe output: press Control-Option-Command-H, explain the synchronous pause,
  then explicitly re-enable only if time and safety permit.
